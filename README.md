# Polyglot Backend Labs

A collection of backend projects and DevOps work by Alimi Lateef Adekunle.

| Folder | What it is |
| --- | --- |
| [Ade-projects/e-commerce-backend](Ade-projects/e-commerce-backend) | NestJS and MongoDB e-commerce API with Docker, CI/CD, Terraform and Helm on AWS EKS |
| [todo-api](todo-api) | NestJS, TypeORM and PostgreSQL Todo API |
| [notes-api](notes-api) | Notes API with database migrations |
| [marketedge-backend](marketedge-backend) | GraphQL fintech and CRM backend: NestJS, MongoDB, Redis and BullMQ, with Docker, CI/CD (tests, Trivy scan, smoke test, ghcr.io) and a Helm chart |
| [sql-practice](sql-practice) | SQL practice exercises |

The CI pipelines for the e-commerce and MarketEdge backends are in [.github/workflows](.github/workflows).
