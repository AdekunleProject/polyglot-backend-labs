# Polyglot Backend Labs

A collection of backend projects and DevOps work by Alimi Lateef Adekunle.

| Folder | What it is |
| --- | --- |
| [chat-api](chat-api) | Messenger backend for a mobile app: chats, groups, media, calls, status posts, a wallet and payments, device linking by QR code, app lock, backups, moderation and admin dashboards. NestJS, PostgreSQL, Redis, Socket.IO, BullMQ, LiveKit |
| [blog-api](blog-api) | Blogging API: the full account system, posts and comments, roles with an audit log, dashboards, reports and a weekly digest. NestJS, PostgreSQL, Redis |
| [Ade-projects/e-commerce-backend](Ade-projects/e-commerce-backend) | NestJS and MongoDB e-commerce API with Docker, CI/CD, Terraform and Helm on AWS EKS |
| [Ade-projects/e-commerce-frontend](Ade-projects/e-commerce-frontend) | React storefront for the e-commerce API |
| [marketedge-backend](marketedge-backend) | GraphQL fintech and CRM backend: NestJS, MongoDB, Redis and BullMQ, with Docker, CI/CD (tests, Trivy scan, smoke test, ghcr.io) and a Helm chart |
| [shop-api](shop-api) | Shop API that shows how to sell the last item to exactly one buyer, with transactions and row locks |
| [notes-api](notes-api) | Notes API with database migrations |
| [todo-api](todo-api) | NestJS, TypeORM and PostgreSQL Todo API |
| [tasks-api](tasks-api) | Task tracker API (in progress) |
| [sql-practice](sql-practice) | SQL practice exercises |

The CI pipelines for the chat, blog, e-commerce and MarketEdge backends are in [.github/workflows](.github/workflows).
